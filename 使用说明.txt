SnapTool — 小巧截图工具 v1.4.0  (免安装)
=====================================

【运行】
  双击 SnapTool.exe,任务栏右下角会出现图标。

【开始截图】
  默认按  Ctrl + Alt + A
  快捷键设置:截图界面顶部点「快捷键设置」，或右键托盘图标 →「设置快捷键」。
  可以直接输入 Ctrl+Alt+A 这样的组合，或点「录制快捷键」后按组合键，再保存。

【截图步骤】
  1. 屏幕变暗后,拖动鼠标框选区域;
     或者把鼠标移到某个窗口上(会自动高亮),单击即可选中整个窗口。
  2. 选区一确定,工具栏自动出现(选区上方有提示条)。此时可:
       · 移动选区:鼠标移入选区(变移动光标),左键拖动
       · 调整大小:鼠标移到选区边或角(变缩放光标),左键拖动
       · 开始标注:点下方「标注」工具栏的矩形/圆形/箭头等，或按 1~9
       · 快速复制:双击 / Ctrl+C / Enter
       · 重新框选:右键
  3. 标注工具:矩形 · 圆形 · 箭头 · 直线 · 画笔 · 文字 · 马赛克 · 序号 · 高亮
     顶部「截图形状」改变图片外轮廓；下方「标注」在截图内容上画记号。
     矩形/圆形可勾「实心」，箭头可勾「双向」，颜色可选 7 种。
     按住 Shift:矩形画正方形，圆形画正圆，直线/箭头按 45° 对齐。
     调节粗细/字号/马赛克粒度:选中工具后按 [ 或 ],或直接滚轮。
     点「选择」(或按 0)再点已有标注：拖动移动，Delete 删除；
     可继续点颜色按钮或滚轮修改样式。空心矩形/圆形请点边线。
     Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。
  4. 完成:
       Enter / Ctrl+C      复制到剪贴板
       Ctrl + S            保存为图片(记住上次目录和格式)
       Ctrl + Shift + S    快存:直接存到「图片\SnapTool」并把文件路径复制到剪贴板
       Ctrl + T            贴图(钉在屏幕上,可拖动、滚轮缩放)

【取色器】
  截图时移动鼠标,光标旁会显示当前像素颜色(色块 + HEX + RGB)。
  按 C 复制 HEX;没有选区时按 Ctrl+C 复制 RGB(...) 格式。

【文字识别 (OCR)】
  框选屏幕上的一段文字 → 工具栏点「OCR」(或 Ctrl + Shift + O)
  → 自动识别(系统自带引擎,本地运行、断网可用;结果窗口独立,关掉截图也不丢)
  → 结果可编辑,点「复制全部」。
  识别语言:右键托盘图标 →「OCR 语言」切换(列表 = 系统已装的语言包)。

【贴图窗口】
  拖动移动 · 滚轮缩放(以鼠标位置为锚点)· Shift+滚轮调透明度
  · Ctrl+C 复制 · T 键切换置顶 · 双击或 Esc 关闭 · 右键出菜单

【托盘菜单】
  截图 / 延迟截图(3·5·10 秒,倒计时不会被截进画面,连点会替换上一个)
  设置快捷键 / 开机自启(一键开关) / 截图时识别贴图窗口(可关) / OCR 语言
  关于 / 退出

【常用快捷键】
  Ctrl + Alt + A      截图(默认,可自定义)
  C                   复制当前像素颜色 HEX(取色器)
  Ctrl + C            有选区:复制截图;无选区:复制 RGB 颜色
  Ctrl + Shift + O    识别选区文字(OCR)
  1 ~ 9               矩形/圆形/箭头/直线/画笔/文字/马赛克/序号/高亮
  0                   选择已有标注(拖动移动)
  Shift + 绘制        正方形/正圆；直线、箭头以 45° 对齐
  [ / ] 或滚轮        调节线宽 / 字号 / 马赛克粒度
  Ctrl + Z            撤销
  Ctrl + Y            重做(Ctrl+Shift+Z 也行)
  Delete / Backspace  删除选中的标注；未选中标注时撤销
  Ctrl + S            保存
  Ctrl + Shift + S    快存
  Ctrl + T            贴图
  Ctrl + R            重选
  Esc                 取消

【系统要求】
  Windows 10 / 11(系统自带 .NET Framework 4.8,无需另装)。
  OCR 用系统自带引擎(识别语言取决于本机安装的语言包)。

【退出】
  右键托盘图标 → 退出。

【小贴士】
  · 双击托盘图标也能截图。
  · 想截菜单、悬停提示等"按出来才出现"的画面?右键托盘图标 → 延迟截图。
  · 开机自启:托盘菜单直接开关,不用手动放快捷方式。
  · 配置文件 SnapTool.config.txt 支持手改(hotkey= / ocr= / pinwin=),
    数字键直接写,如 hotkey=Ctrl+1;exe 目录不可写时会自动存到 %APPDATA%\SnapTool。

【v1.2.0 补充】
  文字输入时 Enter 提交、Esc 取消当前文字；点击工具栏或保存会提交文字。
  再次双击运行中的 SnapTool 会唤起截图，支持 --capture 启动参数。
  快存不再覆盖同秒截图；OCR 进行中关闭截图窗，结果仍会独立显示。
  默认构建输出 artifacts\SnapTool.exe；完整审计见 修复报告.md。

【形状截图 v1.3.0】
  截图顶部顺序：矩形（每次默认）→ 圆形 → 三角形 → 多边形。
  圆形始终为正圆，拖动框选后可移动、缩放。
  多边形菜单含五边形、六边形、自由多边形。自由多边形逐点单击，
  双击/点击首点/Enter 完成，右键或退格撤回一点，完成后 Enter 复制。
  PNG/快存保留透明背景，JPEG/BMP 自动白底；剪贴板透明度取决于粘贴软件支持。

【截图内标注 v1.4.0】
  例如标出一个按钮：框选截图 → 下方「圆形」 → 围着按钮拖动。
  圆形平时画椭圆，按住 Shift 画正圆；矩形仍是默认标注工具。
  画错后 Ctrl+Z；想改位置时按 0，点边线后拖动，不必重新画。
  文字输入期间数字、退格、Ctrl+C/Z 仍用于文字编辑，Enter 提交文字。
  新增标注与重做继续使用 Windows 系统绘图组件，无需额外安装。
  完整对标、绘制性能与验证边界见「对标与性能报告.md」。
